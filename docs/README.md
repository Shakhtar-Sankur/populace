# Report assets

`buzz-run-2026-08-21.svg` is the record of the largest run that was clean end
to end: two hundred concurrent drivers against Buzz across 20 cities in 11
countries, 21 August 2026.

The choice is deliberate. A later run drove 300 drivers through 1,401,435 calls
with zero API failures, but one call never reached the server — a socket
exhausted on the test machine — so its verdict is *inconclusive*. A graphic of
that run headlining "no failures" would need an asterisk. This one needs none.

`buzz-run-2026-08-15.svg` is the previous record and is kept because other pages
still link to it.

Both are generated by `build-run-graphic.mjs`, which holds the run's numbers as
data and **asserts that the per-method call counts sum to the reported total**,
so the picture cannot quietly drift from the figures it claims.

```bash
node docs/build-run-graphic.mjs
```

These runs are against a local Supabase stack, so they are repeatable — and were
repeated: three independent 30-driver runs agreed to within 1.2%. The production
project sits in `neverRunAgainst` and the guard refuses it before the adapter
loads.
