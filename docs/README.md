# Report assets

`buzzbuzz-run-2026-08-09.svg` is the record of Populace's first run against a
real, finished application — Buzz Buzz, 9 August 2026. The `.png` is the same
image rasterised at 2× for slides and social.

Both are generated by `build-run-graphic.mjs`, which holds the run's numbers as
data and **asserts that the per-method call counts sum to the reported total**,
so the picture cannot quietly drift from the figures it claims.

```bash
node docs/build-run-graphic.mjs
```

The run is not repeatable. It executed against a Supabase project that was empty
at the time and is production now, so that project sits in `neverRunAgainst` and
the guard refuses it before the adapter loads. These files are the record of it.
